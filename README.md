# MathParty

Локальная игра для вечеринок на Android с математической тематикой.

## Режимы игры
- Математический Шпион: поиск шпиона среди игроков по наводящим вопросам с выбором курса (11 класс — 4 курс) и уровня сложности.
- Математический Лоб («Кто я?»): угадывание ученых, понятий и парадоксов по подсказкам друзей.
- Испорченный Телефон: передача и зарисовка математических понятий и формул от игрока к игроку.

## Стек технологий
- Kotlin, Jetpack Compose, Material 3
- Офлайн-база терминов + опциональная генерация через OpenAI API
- Поддержка рисования и стилуса S Pen

## Установка
Готовый установочный файл находится в папке apk/MathParty.apk.
